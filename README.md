# HealthSync
App de Monitoramento de Pacientes Crônicos
# Instalação e Configuração

## Clone o Repositório:

git clone https://github.com/arenitoo/HealthSync.git

## Instale as Dependências:

### Backend:

cd backend

`npm install`

### Frontend:

cd frontend

`flutter pub get`

### Configuração do Firebase:

Adicione os arquivos de configuração do Firebase ao projeto Flutter e backend.

### Execute os Serviços:

Inicie o backend:

`npm start`

Inicie o frontend:

`flutter run`
